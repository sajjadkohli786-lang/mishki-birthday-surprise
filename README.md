# Mishki Birthday Surprise — Your Shiku ❤️

A static, mobile-friendly birthday website for Mishki.

## Included
- Countdown to 17 October 2026, 12:00 AM IST, with optional early password access
- Live animated plum/pink background and falling hearts
- Hover effects for text, cards, and photos
- Birthday letter and your handwritten signature
- Three real photos in the Little Moments gallery
- Birthday song in `assets/music.mp3` with a user-controlled music button
- Ten sequential interactive message cards
- Secret envelope letter
- Five-heart collecting mini-game
- “Read This on a Bad Day” message
- Birthday cake celebration, secret message, final gift, and grand finale
- Responsive layout and reduced-motion support

## Files
- `index.html` — website
- `assets/photo1.jpg`, `assets/photo2.jpg`, `assets/photo3.jpg` — your photos
- `assets/music.mp3` — your song
- `assets/signature.png` — your handwritten signature

## Publish with GitHub Pages
1. Extract this ZIP.
2. Create or open your GitHub repository.
3. Upload `index.html`, the `assets` folder, and this README to the repository root.
4. In repository Settings → Pages, select “Deploy from a branch”, choose `main` and `/ (root)`, then save.
5. Open the Pages URL GitHub gives you.

## Early-access password
The default password is `MishkiSurprise2026`. To change it, edit `EARLY_ACCESS_PASSWORD` in `index.html`.

**Note:** This is a client-side password gate, not secure authentication; static website source can be inspected. Music playback requires a tap because browsers commonly block autoplay.
